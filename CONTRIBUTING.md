# Contributing to ScholarLens AI

Thank you for your interest in contributing to ScholarLens AI! This project aims to help parents understand how their children engage with learning activities through AI-powered observations.

## 🚨 Important: Ethical Guidelines

Before contributing, please understand our core principles:

1. **This is NOT an assessment tool** - We observe engagement patterns, not ability
2. **No labeling language** - Never use terms like "slow learner", "struggling", etc.
3. **Child safety first** - All features must protect children's privacy and wellbeing
4. **Professional consultation** - Never suggest this tool can replace professional evaluation

## How to Contribute

### Reporting Bugs

1. Check if the bug has already been reported in [Issues](https://github.com/VIKAS9793/ScholarLensAI/issues)
2. Create a new issue with:
   - Clear title and description
   - Steps to reproduce
   - Expected vs actual behavior
   - Screenshots if applicable

### Suggesting Features

1. Open an issue with the `enhancement` label
2. Describe the feature and its benefit
3. Explain how it aligns with our ethical guidelines

### Code Contributions

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes following our code style
4. Test thoroughly in AI Studio
5. Commit with clear messages: `git commit -m "feat: add your feature"`
6. Push and create a Pull Request

## Code Style

- Use TypeScript for type safety
- Follow React best practices
- Use Tailwind CSS for styling
- Include accessibility attributes (ARIA labels)
- Add comments for complex logic

## AI Safety Checklist

Before submitting any PR that affects AI behavior:

- [ ] Does not use labeling or deficit-based language
- [ ] Includes uncertainty/hedging in AI outputs
- [ ] Provides alternative explanations
- [ ] Does not claim to diagnose or assess ability
- [ ] Respects child privacy (COPPA/GDPR compliance)
